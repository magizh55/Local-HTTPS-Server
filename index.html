📡 How to Verify with Wireshark

  1. Start both servers: Run npm start in the project directory
  2. Open Wireshark → Select the Loopback (lo) interface
  3. Capture HTTP: Filter tcp.port == 8080 → Visit http://localhost:8080 → Right-click a packet → Follow TCP Stream → See plaintext HTML
  4. Capture HTTPS: Filter tcp.port == 8443 → Visit https://localhost:8443 → Right-click a packet → Follow TCP Stream → See encrypted TLS data
  5. TLS Handshake: Filter tls.handshake to see the ClientHello, ServerHello, and certificate exchange
